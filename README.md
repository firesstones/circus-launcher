# Circus Launcher

Circus Launcher est une plateforme communautaire conçue pour centraliser les outils de l'écosystème Circus au sein d'une interface unique.

Son objectif est de simplifier l'installation, la mise à jour et l'accès aux différents outils tout en préparant les futures fonctionnalités de synchronisation et d'intégration entre les services Circus.

---

## Fonctionnalités

* Installation simplifiée des outils compatibles
* Mises à jour centralisées
* Gestion des applications Circus depuis une interface unique
* Accès rapide aux outils installés
* Architecture évolutive permettant l'intégration de nouveaux outils et services

---

## Outils Circus

Le launcher est conçu pour accueillir les outils actuels et futurs de l'écosystème Circus.

Projets actuellement intégrés ou prévus :

* Circus VOIP
* Circus OCR
* Circus Racing
* Circus Auto
* Circus Config

Cette liste évoluera au fur et à mesure du développement de nouveaux projets.

---

## Fonctionnalités prévues

Certaines fonctionnalités sont actuellement en développement ou prévues pour les futures versions :

* Authentification Discord
* Synchronisation cloud des paramètres utilisateur
* Sauvegarde et restauration des presets
* Synchronisation entre plusieurs ordinateurs
* Intégration avancée des services Circus
* Intégration avec Circus Event
* Notifications et services connectés

Les fonctionnalités présentées ci-dessus sont susceptibles d'évoluer au cours du développement du projet.

## Signaler un problème

Si vous rencontrez un bug ou souhaitez proposer une amélioration :

* Ouvrez une Issue GitHub
* Décrivez le problème le plus précisément possible
* Ajoutez des captures d'écran ou des logs lorsque cela est pertinent

Des raccourcis permettant d'accéder directement aux Issues GitHub sont également disponibles depuis le launcher lorsque l'outil concerné les propose.

Les retours de la communauté sont essentiels à l'amélioration du projet.
